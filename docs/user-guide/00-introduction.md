# Inventory Management & Tracking

## About this guide

This guide is a reference. It is not a course — you will have been shown the
system in person — and it is not meant to be read front to back. Find the part
that matches what you do, and come back to it when you need to check something.

Every screen you can reach is described here, along with **what belongs in each
field** and what happens after you save.

### Which part applies to you

| If you… | Read |
|---|---|
| count stock at a site | Part 1, then **Part 2 — Growers** |
| supply items and report what you hold | Part 1, then **Part 3 — Vendors** |
| set the system up and keep it running | Part 1, then **Part 4 — Administration** |

**Part 1 is short and applies to everyone.** It explains four or five ideas that
the rest of the system is built on. Skipping it is the most common reason people
find a screen confusing later.

**Part 5** is reference material for everyone: a glossary, the full list of
statuses, what the system sends by email, and what to do when something looks
wrong.

## Signing in

There are two ways in, and which one you use depends on who you are. You do not
choose — the one that applies to you is the one that will work. The sign-in
screen is one card with two sections: **Grower or vendor?** at the top and,
below an *or*, **Company staff?**

### Staff of the company running the system

Select **Sign in with Microsoft** and use your normal work account. There is no
separate password for this system. If you have more than one Microsoft account,
**Use a different Microsoft account** lets you choose which one.

If you see *"This account doesn't have access to this app"*, your sign-in worked
but nobody has given you access yet. Select **Try a different Microsoft
account** if you have another work account; otherwise ask your administrator to
add you.

### Growers and vendors

Enter your email address and select **Email me a sign-in link**. A message
arrives with a link that signs you in when you select it. The address is
remembered on that computer and filled in next time.

- The link lasts **15 minutes** and works **once**. Select **Resend link**
  (available after 30 seconds) whenever you need another; asking for a new link
  cancels the previous one.
- Use the most recent email. An older link will no longer work.
- If nothing arrives, check your Spam or Junk folder — it can take a minute —
  then the spelling, then ask your contact whether the address on file is the
  one you typed.
- If a link cannot be sent, the screen says why: the address is not registered,
  it belongs to company staff (who use the Microsoft button instead), or your
  account or organisation has been turned off. §5.4 lists each message.

You stay signed in for about a week, and that resets each time you use the
system, so regular users are rarely asked again. On a shared computer, use
**Sign out** when you finish.

## Finding your way around

The menu on the left changes with your role — you only ever see what applies to
you. On a phone, open it with the button at the top left.

Some menu entries carry a number. A **coloured** badge means work is waiting for
someone; a **grey** badge is a count for information only, and does not need
action.

## Changing the language

The system is available in **English** and **Spanish**. Use the language control
in the top bar to switch; the choice is remembered for next time, including on a
different computer.

That choice also sets the language of emails sent **to you personally**, such as
sign-in links.

Emails sent to an **organisation** — submission confirmations and reminders,
which go to the address held against the grower or vendor record — use the
language set on that record instead. Only an administrator can change it
(§4.5).

## Getting help

Contact your usual administrator. It saves time if you can say which screen you
were on, what you were trying to do, and the exact wording of any message shown.
